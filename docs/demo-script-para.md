# Script in paragraphs — just read

Read each paragraph out loud, in order. Do the small [action] when you see it.

---

## Paragraph 1 — the problem

Ok.Recording on hai.Now read this paragraph, slowly:

"Small sellers in Pakistan already face a lot of pressure. Some of them have no website at all — they run everything on WhatsApp and Instagram, and every order is just a message in chat. So they forget orders, ship late, and lose customers. Other sellers have website systems like Shopify, WooCommerce, or their own custom PHP sites. But even for them, daily work is endless clicking — open admin panel, find the order, mark it shipped, again and again, every single day. Now imagine instead that the seller can simply talk — like talking to an assistant — and the store does the work by itself."

[Pause 2 seconds. Show the browser screen.]

---

## Paragraph 2 — what I built

"I built Storefront Voice Ops. It is a voice agent for your store — like Alexa, but for a shop. You speak in normal language: how much did we sell today, what is low in stock, which orders are waiting to ship. The agent understands and does the work. And it acts like a careful human, not a crazy robot — before it ships or cancels anything in your real store, it asks you first — yes or no — and every action is written to an audit log, so you always know what happened and when."

[Point mouse at the chat box "Talk to your store".]

---

## Paragraph 3 — live demo on real store

"Now this is not a fake demo. This screen is connected to my real website, kapraa dot pk — a real PHP and MySQL site running on live hosting, right now. Watch."

[Type: How did my store do today? Wait for answer.]

"See — real sales, in real rupees, from my live website."

[Type: What is running low? Wait.]

"These are real products from my store that need restocking — the same SKUs you see on my admin panel."

[Say with mic: What orders are pending? Wait.]

"Real orders, real customers, live from my store database. Now the important part — shipping. I will say ship an order with a courier, and see what it does."

[Say with mic: Ship order [ID from the list] with Leopards.]

[Yes/No card appears. Click Yes.]

"It asked me first. Only my yes made it real. And here in the audit log — order shipped, courier, time — every action is recorded."

[Scroll to the Inspector panel and point.]

"Tools it used, timestamps, results — full proof on screen."

---

## Paragraph 4 — the best part

"And here is the part I am most proud of. This agent is not limited to one platform. It has a Shopify adapter — it connects to a real Shopify store with an admin token. It has a WooCommerce adapter — standard REST keys, ready. And for completely custom-coded websites, even a basic PHP plus MySQL site — like mine — there is a small JSON API file that bridges any website into this platform. But the biggest idea is this: what about sellers who have no website at all? WhatsApp sellers, Instagram sellers — no site, no system. For them the app has a manual store mode — add your products right here, record your orders right here, and the same voice agent handles shipping and stock exactly like it does for Shopify. And if you have many stores — Shopify plus custom plus manual — you create one profile for each, and switch between them in one click, in one app."

[Open + Add store, show dropdown slowly, then press Cancel.]

---

## Paragraph 5 — safe by design

"Voice can break a real store, so safety is built in. Nothing writes to a store without spoken confirmation. Kids' situations like double orders are blocked — one pending action per order. Requests expire if you don't answer. Everything is rate-limited and logged. And for trying it out there is a practice store with fake data — zero risk, full experience."

---

## Paragraph 6 — ending

"So that is Storefront Voice Ops — from a WhatsApp group to a Shopify giant, one voice assistant that runs every kind of store. The complete code is open source on GitHub, with tests, docs, and CI. Thank you."

[Stay on screen 3 seconds. Then stop recording.]
