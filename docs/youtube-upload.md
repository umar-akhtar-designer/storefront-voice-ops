## Description (paste whole)

Storefront Voice Ops — a voice agent for every kind of store, built for the Amazon Developers Hackathon (Alexa+ track).

Speak to your store the way you'd speak to a careful assistant:

• "How did my store do today?" — real sales, real currency
• "What is running low?" — live low-stock alerts with SKUs
• "What orders are pending?" — live customers and totals
• "Ship order <id> with Leopards/PostEx/CallCourier" — asks Yes/No first, then ships and writes the audit trail

WHO IT'S FOR:
• Shopify sellers — first-class adapter, name-based order lookup, inventory writes
• WooCommerce sellers — standard REST keys, zero special setup
• Custom-coded websites — even a plain PHP + MySQL site joins through one small JSON API file (full kit in the repo — this demo is connected LIVE to a real Pakistani store, kapraa.pk)
• Sellers with NO website — WhatsApp/Instagram-only sellers get a manual store mode: add products, record orders, and the same voice agent runs shipping and stock
• Many stores? One profile each, switch in one click — one app for all of them

SAFETY BY DESIGN: spoken confirmation before every write, one pending action per order, expiring requests, rate limits, and a complete audit log with the MCP tool calls that made it happen.

Stack: Node, TypeScript, Express, MCP (the Alexa+ protocol), SQLite, adapters for Shopify/WooCommerce/custom stores. 170+ green tests + browser end-to-end tests in CI.
